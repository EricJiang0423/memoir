产品

不是相册导出，是一次完整的编辑流程。

memoir 把 agent 能力拆成明确流水线：先读取本地照片元数据，再做地理聚类和品质预检，随后由 agent 做视觉策展、中文叙述和页面设计。交付物不是 dashboard，也不是模板站，而是一份能双击打开的旅行回忆 HTML。

从 2000 张照片里，留下真正能讲故事的部分。

模糊、截图、重复连拍、票据和无意义转场被挡在作品外。每张入册照片都要能回答：它为什么值得出现？

  1. 01EXIF 提取：时间、GPS、相机文件状态。
  2. 02地理聚类：按日期、坐标和移动距离组织行程。
  3. 03品质预检：模糊、曝光、截图、重复和连拍。
  4. 04策展写作：标题、每日叙述、照片 caption。
  5. 05现场设计：按旅行气质生成独立 HTML。

能力

一个给 agent 使用的旅行回忆录系统。

memoir 的核心不是一个网页模板，而是一组可安装的 skill 指令、Python 脚本和设计方向协议。它让 Codex、Claude Code、Cursor 等 agent 能按同一套质量门槛完成本地照片处理和最终作品生成。

Privacy
照片字节留在本机。

除 GPS 坐标用于 Nominatim 地名查询外，EXIF、缩放、策展和 HTML 后处理都在本地完成。

Curation
先删，再写。

contact sheet 一次读完全局，结合机器预检和视觉判断，避免把网页变成照片垃圾桶。

Design Pool
NEVER converge。

大画册、手帐、宽银幕、暗房、Zine、极简白，每个方向都有不同布局 archetype。

Delivery
单文件交付。

照片 token、Leaflet、JSON 数据由后处理注入；最终 HTML 可拖进浏览器，也可发布到静态托管。

画廊

同一组京都照片，六种完全不同的阅读方式。

这些变体共用同一批精选图，但每个页面的结构、照片处理、字体和节奏都不同。这里展示的是 skill 的设计方向池，而不只是 CSS 换皮。

Heritage Album

大画册

深棕底、米黄册页、照片贴卡纸。适合历史城市和人文旅行。

打开版本
Traveler Notebook

旅行手帐

打开版本
CinemaScope

宽银幕

黑场、宽画幅、极少文字。像一部旅行短片的分镜。

打开版本
Darkroom

暗房

黑白接触印相、高反差、少解释。让照片自己站住。

打开版本
Zine

复印机质感、拼贴、重叠和裁切。反精致，但有态度。

极简白

安装

把 memoir 装进你的 agent 工作流。

仓库根目录负责展示和 GitHub Pages；真正的可安装 skill 在 skill/ 目录。复制或 symlink 后，agent 会按 SKILL.md 驱动整个照片到 HTML 的流程。

快速安装

适用于 Claude Code，也适用于能读取本地 skill 目录的 agent 环境。

git clone https://github.com/EricJiang0423/memoir.git
cd memoir
ln -sf "$(pwd)/skill" ~/.claude/skills/memoir
pip install -r skill/requirements.txt

产品承诺

  • 本地优先照片不上传到图床或云端视觉 API。
  • 有审美纪律先策展，再叙述，再设计，不做模板相册。
  • 可复现流水线脚本之间只通过 JSON 文件交接，方便调试和二次开发。
  • 静态可部署最终作品和这个首页都能直接放到 GitHub Pages。
