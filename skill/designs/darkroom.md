# 暗房（Darkroom）

## 气质

粗粝、高反差、地下感。像暗房里冲出来的接触印相。黑到底，白到刺眼，中间调尽可能少。城市夜晚、地下音乐场景、废弃建筑——所有"不漂亮"的旅行。

## 适用场景

城市夜行、地下俱乐部、废墟探索、雪地/沙漠高反差。照片欠曝或高对比时最好。不适合明亮可爱的旅行。

## 布局 Archetype

```
[出血封面——满版全黑，只有标题白字挤在右下角]
  ↓
[接触印相页——6 张照片排成 3×2 网格，黑白滤镜，极细白边框]
  - 每张图缩小到 28vw × 20vw
  - 无文字、无 caption
  ↓
[全幅单页——一张照片全屏，黑底出血，极度安静]
  - 只有照片，没有文字
  ↓
[接触印相页 2——再一组 3×2]
  ↓
[双联——两张照片左右各半屏，中间黑缝 2px]
  ↓
[全幅单页] → [印相页] → [双联] ......
  ↓
[封底——黑底 + 白字 trip-design + 隐私说明，字号 0.6rem 极小]
```

**不按日期分章。** 照片只按视觉节奏排列：紧张（接触印相密集）→ 释放（全幅单页）→ 紧张（双联对峙）……

## 色彩

- 底：纯黑 `oklch(0 0 0)`
- 文字：纯白 `oklch(1 0 0)`
- 可选极端 accent：暗红 `oklch(0.35 0.12 25)` 只出现在封面标题或封底线
- 所有照片加 `filter: grayscale(80%) contrast(1.3)`（模拟暗房印相）
- 不接受彩色。照片的原始色彩被暗房处理覆盖

## 字体

- 唯一字体：`"SF Mono"` / `"JetBrains Mono"` / `ui-monospace`
- 字距极宽（`letter-spacing: 0.3em`）
- 封面标题 `clamp(2rem, 5vw, 4rem)`
- 封底文字 `0.6rem`，不显眼

## 照片处理

- CSS 滤镜：`grayscale(80%) contrast(1.3) brightness(1.1)`
- 印相页照片边框：`1px solid oklch(0.4 0 0)`
- 全幅照片无边框
- 不要保护高光/阴影——允许照片纯黑、纯白溢出

## 地图

不要地图。如果路线信息重要，用一行文字交代（"新宿→下北沢→渋谷"），黑底白字。

## 灯箱

照片已经是大幅展示，不需要灯箱。印相页点击可展开为全幅（用简单 JS toggle，扩展动画 0.2s ease）。

## 动画

- 无入场动画
- 印相页照片 hover：亮度 +0.15，极短 0.15s
- 全幅照片进入 viewport 时 0.3s 淡入（从纯黑浮现）

## 严禁

- ❌ 暖色 / 彩色 / 渐变
- ❌ 衬线 / 手写 / 装饰字体
- ❌ 叙事段落 / 散文 / daily narrative
- ❌ 地图
- ❌ 圆角 / 卡片 / 毛玻璃
- ❌ 标题装饰 / emoji

## 推荐理由

选这个方向当且仅当：用户明确说"黑白"、"粗粝"、"不想看文字"或者照片内容明显是城市/夜晚/反叛气质。
