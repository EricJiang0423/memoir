# 大画册（Heritage Album）

## 气质

厚重、典藏。像博物馆的藏品图录，或皇家地理学会的探险记录。深色底（深棕 / 深绿），照片像贴在册页上，文字像手写标签。

## 适用场景

历史城市（京都 / 罗马 / 伊斯坦布尔）、博物馆、教堂、人文深度游。照片本身色调偏暖偏暗时效果最好。不适用于亮丽轻快的旅行。

## 布局 Archetype

```
[翻页封面——单张厚纸色块 + 烫金标题]
  ↓
[章节衬页——深棕纯色 + 章节编号，不跨屏]
  ↓
[跨页对开——左页满版照片，右页正文 + 手写标签]
  - 照片带极细描边（#d4c9a8），稍微旋转（0.3-1.2deg）
  - 正文短，留白大
  ↓
[四宫格图版——2×2 网格，每格加黑框 + 编号]
  ↓
[章节衬页] → [跨页] → [多图版] ……
  ↓
[封底——单色 + 版权小字]
```

**没有地图。没有灯箱。** 如果路线复杂必须地图，做成极小索引放在封底。

## 色彩

- 底纸：`oklch(0.45 0.04 60)`（深棕）
- 前景面纸：`oklch(0.92 0.012 75)`（米黄）
- 文字：`oklch(0.15 0.02 60)`（深褐）
- 点缀：`oklch(0.65 0.08 55)`（金）或 `oklch(0.70 0.04 200)`（铜绿）
- 照片边框：前景面的深一阶 `oklch(0.80 0.02 70)`

从照片取色时，取一张暖调、低饱和的照片做主色。

## 字体

- 标题：`"Songti SC"` / `"Noto Serif SC"` / `Georgia`，粗体，字距宽
- 正文：`"STSong"` / `"Noto Serif"`，常规，小号
- 标签/脚注：`"SF Mono"` / `"Courier"`，极小型大写
- 首字下沉（标题或正文首段）

## 照片处理

- 每张照片加 1px 深棕描边 + 3-5px 米白色衬边（像贴卡纸）
- 轻微随机旋转（0.3-1.2deg）模拟手工粘贴
- 可选极淡投影（`0 2px 8px oklch(0 0 0 / 0.10)`）
- 不要给每张照片都写 caption。只在跨页右边区块留文字空间

## 动画

- 无入场动画。页面加载后章节衬页以 0.6s 淡入
- 唯一的动效：照片悬停时描边变金色，持续 0.3s
- 无滚动视差，无 fade-in reveal

## 严禁

- ❌ 地图 / 路线索引（除非封底极小地图）
- ❌ 灯箱 / 点击放大
- ❌ 毛玻璃 / 模糊背景
- ❌ 现代风格（无圆角、无鲜艳 accent、无渐变）
- ❌ 照片的 caption 超过 12 字

## 推荐理由

选这个方向当且仅当：照片偏暗偏暖，旅行有历史感，用户想要一件"可以打印出来放书架上的东西"。
