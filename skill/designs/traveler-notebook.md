# 旅行手帐（Traveler's Notebook）

## 气质

私人、亲笔、不完美。像野外笔记本——咖啡渍边缘、手写批注、胶带贴上去的拍立得。不要整齐，要「这是有人真的写过」的感觉。

## 适用场景

独自旅行、公路旅行、田野笔记、探险。照片质量参差不齐时最适合——手帐风格本身接纳"不完美"的照片。

## 布局 Archetype

```
[封面——牛皮纸色块 + 手写体标题 + 日期]
  ↓
[跨页日记——左页 1-2 张照片（拍立得边框），右页叙述体正文]
  - 照片带粗白边框 + 极淡阴影，可倾斜
  - 正文手写体，首段首字粗大
  ↓
[资料页——票据 / 地图碎片 / 手绘路线图]
  - 用 CSS 画一条极简路线（不用 Leaflet）
  - 路线旁标注时间标签，像手写笔记
  ↓
[跨页日记] → [资料页] → [跨页] ……
  ↓
[封底——一小段后记 + 手写签名]
```

**不用灯箱。不用 Leaflet 地图。** 路线用纯 CSS/SVG 手绘线。

## 色彩

- 底：`oklch(0.96 0.015 85)`（牛皮纸米色）
- 文字：`oklch(0.20 0.03 60)`（深褐色）
- accent：`oklch(0.60 0.06 30)`（锈红）或 `oklch(0.40 0.04 220)`（墨水蓝）
- 照片边框：纯白 `4-6px`，微投影
- 胶带色块：半透明彩条（`oklch(0.85 0.05 80 / 0.3)` 黄 / 蓝 / 粉）

从照片里取最暖的色当锈红 accent。

## 字体

- 标题：`"KaiTi"` / `"STKaiti"` / `"LXGW WenKai"`（中文楷体）或 `"Caveat"` / `"Patrick Hand"`（英文手写）
- 正文：手写体（`"KaiTi"` / `"LXGW WenKai"`），行距 1.8
- 标签：`"SF Mono"` / `"Courier New"`，8px
- 如果手写 Web font 太大无法内嵌，用系统楷体 + small-caps 模拟

## 照片处理

- 每张照片 4px 白边（像拍立得），1px `#d9d0c0` 描边
- 可倾斜（`rotate(-0.5 ~ 1deg)`），模拟随手贴上
- 覆盖半透明"胶带"条（`:before` 伪元素 + 背景色块）
- 允许照片之间有重叠（`margin: -10px` 等）

## 动画

- 无入场动画
- hover 时胶带变不透明、照片轻微上浮
- 翻页感：章节用左/右边界突破模拟跨页

## 严禁

- ❌ 地图 / Leaflet
- ❌ 灯箱（照片已经 inline 展示）
- ❌ 完美对齐的网格
- ❌ CSS 圆角 / 毛玻璃
- ❌ 全屏 Hero

## 推荐理由

选这个方向当且仅当：旅行是个人探索性质的、照片不追求完美的光影构图、用户想要一本"像自己写的东西"。
